# 丛鱼的家

一个可以直接部署到 GitHub Pages 的静态个人网站，包含：

- 固定顶部导航与移动端菜单
- 首页与个人简介
- 本地头像与首页自动播放的动态信息拼贴
- 浏览器端文档转换工具
- 浏览器端图片文字提取工具
- 浏览器端图片去水印与局部修复工具
- 八指标 AI 写作特征分析、风险区间与段落定位
- 可搜索、筛选和切换视图的网页导航
- 三个学期的彩色课表与完整课程信息
- 深色/浅色主题

## 本地查看

网站没有构建步骤。可以直接打开 `index.html`，也可以在项目目录运行任意静态文件服务器。

例如：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 部署到 GitHub Pages

1. 在 GitHub 创建一个新仓库。
2. 将本文件夹中的所有文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择 `main` 分支和 `/ (root)` 目录并保存。
6. 等待 GitHub 给出公开网址。

网站使用 `#/about`、`#/tools` 等 Hash 路由，因此不需要配置服务器重写规则。

## 修改网站内容

主要内容都保存在：

```text
content/site-data.js
```

其中包括：

- `profile`：个人简介
- `categories`：网页分类
- `bookmarks`：常用网页
- `periods`：上课节次与时间
- `semesters`：学期、课程和上课安排

修改并提交这个文件后，GitHub Pages 会自动更新网站。

## 工具能力边界

### 文档转换

目前支持：

- TXT
- Markdown
- HTML
- JSON
- CSV

所有读取和转换默认在浏览器本地完成。当前版本不提供 Word、Excel、PPT 和 PDF 之间的高保真任意互转。

### 图片文字提取

支持上传 JPG、PNG、WebP 和 BMP 图片，识别简体中文、英文或中英混排文字，并可复制或下载为 TXT。图片会在当前浏览器中预处理和识别，不会主动上传；首次使用某种语言时需要联网加载 Tesseract.js 识别组件及语言模型，之后浏览器可能会使用缓存加快加载。

为获得更好的结果，建议使用文字清晰、拍摄端正、对比明显的截图或扫描件。手写体、严重倾斜、低分辨率和复杂背景图片的识别准确率会下降。

### 图片去水印

支持在浏览器中用画笔或矩形标记水印区域，并通过邻近像素填补、半透明水印反向还原或仿制画笔进行局部修复。所有处理都在本机完成，不调用付费接口。自动算法无法还原水印遮挡下从未出现在图片中的真实细节，复杂背景建议配合仿制取样手动细调。请仅处理本人拥有或已获授权的图片。

### AI 写作特征分析

该工具会根据重复表达、模板化表达、句子节奏、词汇变化、段落对称、连接词、标点节奏与具体细节八项指标生成“AI 写作特征指数”，并按照文本长度显示可信度和估计区间。结果不能证明文章由 AI 或人类创作。
